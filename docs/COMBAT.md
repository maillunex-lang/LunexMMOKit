# Combat
Real-time target-based action combat, manual skills and optional autoattack/autobattle. Use original skill groups and shortcut semantics; four active slots no longer assumed. Server validates target, range, cooldown, resources and hit schedule. Client predicts presentation only. Animation event mapping includes windup, hit, recovery, cancel, VFX and audio; one authoritative hit per event ID. Celestial form temporary, energy earned in combat, cooldown, no dragon transformations. Monster AI patrol/aggro/leash/attack/return/death. Boss telegraphs and avoidable attacks. Exact damage coefficients and timings tune using imported clips and playtests.
