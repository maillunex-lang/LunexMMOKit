# Lunex World Editor — инструкция для владельца (без программирования)

## Что это
Плагин Godot 4 для правки города и локаций игры «Осколки вечности». Все правки сохраняются в обычные сцены `.tscn`, которые можно снова открыть на Windows.

## Как открыть
1. Установите Godot 4.x (версия проекта — см. `docs` / CI).
2. Склонируйте репозиторий LunexMMOKit.
3. Синхронизируйте адаптированные ресурсы (см. `docs/PORTABILITY.md`): папка `assets/studio` или переменная `LUNEX_STUDIO_CACHE`.
4. Откройте папку `client/` как проект Godot.
5. В меню **Project → Project Settings → Plugins** включите **Lunex World Editor**.

## Как править столицу
1. Откройте сцену `world/locations/eternity_capital/eternity_capital.tscn` (ваша редактируемая копия).
2. В левой панели плагина найдите нужный объект (поиск и категории).
3. Дважды кликните по киту — объект появится в сцене.
4. Двигайте / вращайте / масштабируйте стандартными инструментами Godot (Q/W/E/R).
5. **Файл → Сохранить сцену** (Ctrl+S).
6. Меню **Project → Tools → Lunex: Write owner.lock** — защита от случайной перезаписи генератором.
7. **Lunex: Bake Location NavigationMesh** — пересчитать пути вокруг зданий.
8. **Lunex: Validate Location** — проверить ошибки; клик по строке выделяет объект.

## Важно
- Генераторы пишут только в `*_generated.tscn`. Ваша сцена с `owner.lock` не перезаписывается без явного подтверждения.
- Не удаляйте `stable_id` / `instance_id` у NPC и порталов — на них завязаны квесты.
- Undo/Redo (Ctrl+Z / Ctrl+Shift+Z) отменяет конкретный объект, не «все дома с похожим именем».
- Оригинальный проект Darklord в игру не кладётся; нужны только адаптированные GLB из `assets/studio`.

## Если что-то сломалось
Сделайте копию файла сцены перед большими правками. При необходимости восстановите из git или из `*_generated.tscn` (это черновик генератора, не затирайте свой owner-файл поверх без бэкапа).
