# BETA-001 — Closed Beta 0.1.0 «Осколки вечности»

## Конечная цель
Полноценная закрытая бета MMORPG, готовая к тестированию реальными игроками.
**Не** демонстрационный City Preview APK. Промежуточные APK допустимы только для внутренней проверки.

| Поле | Значение |
|------|----------|
| Название | Осколки вечности |
| Версия | Closed Beta 0.1.0 |
| Проект | LunexMMOKit |
| Клиент | Godot 4, Android ≥6 ГБ ОЗУ |
| Сервер | Go, PostgreSQL, HTTPS/WebSocket (авторитетный) |

## Обязательное содержание
Реальный сервер + PostgreSQL; регистрация/логин; создание/выбор персонажа; 4 класса Darklord; сохранение прогресса; своя столица; ≥3 боевые локации; глава 1; основные/доп. квесты; NPC/диалоги/торговцы; монстры/элиты/боссы; джойстик; автопуть к квестовым целям; ручной бой + автобой; классовые умения; синхрон анимаций/урона/звуков/VFX; опыт/уровни; статы; БМ; инвентарь; экипировка; лут; улучшение экипировки; крылья; питомцы; маунты; видимость других игроков; чат; смерть/респаун; настройки графики/звука/управления; базовая админка; Lunex World Editor; редактор креплений.

## Этапы к бете (измеримая приёмка)

### B0 — Архитектурный фундамент (AUDIT-001)
Кроссплатформенность без VPS-путей; стабильные ID; защита owner-сцен; NavMesh по геометрии; Undo/Redo; валидатор; единая сессия; единый бой; мобильный HUD; интеграционные тесты.
**Приёмка:** `docs/AUDIT_001.md` по каждому FIX: исправлено / частично / нет + доказательства.

### B1 — Данные и переносимость (D01–D05, F03)
Инвентаризация Darklord; парсеры; GLB/материалы; VFX/аудио; версии Godot/Go/CI.
**Приёмка:** манифесты, отчёты конфликтов ID, private pack + verify.

### B2 — Авторитетный сервер (F04, N01, N02)
Compose+PostgreSQL изолированно; health; auth; персонажи; сессии; AOI; движение.
**Приёмка:** два клиента; просроченный токен отклонён; позиция авторитетна на сервере.

### B3 — Мир и герой (W01–W02, A01–A02, WE03, WD02)
Столица + ≥3 боевые локации; коллизии/nav; 4 класса; анимации/VFX; World Editor для владельца.
**Приёмка:** скриншоты локаций; герой обходит препятствие по NavMesh; owner-edit не затирается.

### B4 — Бой и прогрессия (C01–C03, R01–R02)
Серверный бой; монстры/лут; автобой; уровни/инвентарь/экип/БМ; крылья/питомцы/маунты.
**Приёмка:** урон/HP/лут только с сервера; формулы из Darklord-таблиц после валидации.

### B5 — Квесты и сюжет (Q01–Q02)
Движок квестов; глава 1; обучение; без дублей наград.
**Приёмка:** полный проход главы 1; re-login сохраняет прогресс; повторная награда невозможна.

### B6 — Соцсеть и операции (M01, O01)
Чат; видимость игроков; базовая админка RBAC.
**Приёмка:** два аккаунта видят друг друга и обмениваются сообщениями в чате.

### B7 — Android и релиз беты (P01, L01 / BETA01)
Пресеты Low/Med/High/Max; LOD; лимит видимых игроков; докачка+integrity; APK для iQOO 15R / Xiaomi 13T Pro / Poco X5.
**Приёмка:** установка → регистрация → персонаж → обучение → квесты → бой → экип → другие игроки; progress persist после рестарта; нет блокеров главы 1.
