# Сюжет
Утвержденная основа: CONCEPT-002 C — Осколки вечности.
Тысячу лет назад разрушилось Сердце Вечности, источник магии мира. Осколки рассеялись по континентам, породив чудовищ и пробудив древних богов. Герой обнаруживает способность поглощать небесную энергию, путешествует по королевствам, раскрывает тайны прошлого и становится одним из защитников мира.
Главы, персонажи и детали мира предстоит согласовать.

## Кампания (проектная основа)
1. Пограничье: герой переживает нападение чудовищ, спасает поселение и находит первый осколок. Обучение, город, лес, руины, первый босс.
2. Расколотая столица: расследование происхождения осколков, знакомство с орденом хранителей.
3. Пепельный рубеж: экспедиция в зараженные земли, раскрытие связи чудовищ с древней магией.
4. Небесные врата: открытие пути к храмам богов и конфликт хранителей.
5. Падший хранитель: противник пытается собрать Сердце Вечности ценой гибели королевств.
6. Новый рассвет: предотвращение катастрофы; оставшиеся осколки открывают следующие главы.
Имена и география рабочие. Первая глава реализуется первой; остальные не блокируют вертикальный срез.
