# DGI-005 / KIMI roadmap

Этапы выполняются последовательно с сохранением доказательств после каждого проверенного шага.

| ID | Этап | Критерий перехода |
|---|---|---|
| KIMI-001 | Технический аудит четырёх персонажей | Есть отчёт по скелетам, материалам, анимациям, точкам крепления и manifest-статусам |
| KIMI-002 | Точная универсальная система крепления оружия | Воин/маг/лучник/ассасин держат оружие корректно в ключевых анимациях |
| KIMI-003 | Восстановление оригинальных материалов | Текстуры/параметры материалов применены без белых потерянных поверхностей |
| KIMI-004 | Универсальный конвертер Unity ParticleSystem → Godot | Поддержаны curves/gradients/bursts/shape/blending/mesh particles поэтапно |
| KIMI-005 | Полное восстановление первой атаки мага | Умение 1000001 проходит полный визуальный цикл атаки |
| KIMI-006 | Атаки остальных классов | Умения 2000001/3000001/4000001 перенесены через общий SkillData |
| KIMI-007 | Синхронизация анимаций | События/звук/эффекты синхронны на 0.5/1.0/1.5/2.0x |
| KIMI-008 | Тренировочный полигон | Сцена в `client/scenes/training/` управляется из проекта |
| KIMI-009 | Реальные визуальные тесты | Получены и проверены кадры Godot через Xvfb/Mesa |
| KIMI-010 | Крылья, питомцы, ездовые животные | Есть универсальная система аксессуаров и проверенные представители |
| KIMI-011 | Lunex Character Studio | Основа Android-студии с двумя режимами |
| KIMI-012 | Оптимизация Android | Пресеты качества/частиц/FPS и профилирование без подмены Mesa на Android |
| KIMI-013 | Обновление лендинга | Лендинг обновлён только после одобренных визуальных результатов |
| KIMI-014 | Демонстрационный APK | Собран debug APK, отчёт по размеру и ограничениям |

Текущие частные данные: `/home/gamedev/darklord-dgi/exports`, `screens`, `catalog.sqlite`.
