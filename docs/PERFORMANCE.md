# Performance
Android landscape, minimum target 6 GB RAM; 30 FPS baseline, 60 optional. Compatibility renderer baseline, evaluate Mobile Vulkan separately. Chunk streaming, LOD, texture compression, pooling, visibility and particle caps. Profile actual low/mid/high devices; report frame-time p50/p95, memory, draw calls, load time and thermal behavior. No claim of performance without measurements. APK debug first; release signing secrets outside repo. Asset manifest hashes, resumable downloads and rollback. Server load tests on isolated environment, backup restore before launch.
