# WE03

WORLD-EDITOR-003: Lunex World Editor — нативный Godot 4 EditorPlugin для ручного редактирования локаций владельцем на Windows без программирования.

## Acceptance
Плагин с библиотекой китов (превью/поиск), drag-and-drop, move/rotate/scale, snap-to-ground, правки материалов, маркеры NPC/монстров/порталов/spawn со stable_id, авто-коллизии, кнопка Bake NavigationMesh, валидаторы reachability/auto-path/floating/intersections, Undo/Redo, owner overlay не затирается генераторами, клиент/сервер location_revision согласованы. Сценарий: сдвинуть здание → bake nav → герой обходит по NavMesh.

## Evidence
Спека `docs/WORLD_EDITOR_003.md`. Каркас addon `client/addons/lunex_world_editor/`. Генераторы WD02: guard owner lock. Полная реализация UX и bake-сценарий — в работе задачи WE03.
