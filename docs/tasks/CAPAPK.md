# CAPAPK

Отдельный тестовый APK города, не заменять Character Studio и не выдавать за готовую MMO.

## Acceptance
Четыре класса, джойстик без tap-to-move, камера, коллизии, FPS, графические пресеты. Оружие/крылья/маунты через Attachment System (CHAR08). Проверить экспорт, подпись, SHA256 и HTTP загрузку. Установка и FPS на реальных устройствах требуют отдельного подтверждения. Публиковать только в согласованном месте.
