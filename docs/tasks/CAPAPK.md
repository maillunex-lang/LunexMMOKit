# CAPAPK — внутренний smoke APK (не продукт)

**BETA-001:** конечная цель — Closed Beta 0.1.0 (`docs/BETA_001.md`), не City Preview.

Этот пункт сохраняет возможность собрать технический Android APK для внутренней проверки города/джойстика после AUDIT01 и визуальной приёмки WD02.

## Acceptance
Debug/internal APK только. Не публиковать как релиз MMO. Четыре класса, джойстик без tap-to-move, камера, FPS overlay, графические пресеты. Подпись/SHA256 — для внутренней раздачи владельцу. Установка и FPS на реальных устройствах — отдельное подтверждение; Xvfb FPS не считается.
